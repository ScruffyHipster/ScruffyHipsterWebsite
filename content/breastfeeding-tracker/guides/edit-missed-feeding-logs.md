# When the feed starts before the timer

It is normal to remember the timer after the feed has already begun. Breastfeeding Tracker & Timer includes an adjust control so you can move the recorded start time back instead of discarding the session.

Start the timer when you remember, open the adjustment control, and set the earlier start that you want the history to contain. The running duration updates from that corrected time.

# Add a completely missed session

If the feed has already finished, add it manually from the history view. Enter the details you want to keep, including the side and timing, then save it alongside the automatically timed entries.

Manual entries use the same history as feeds started on iPhone or Apple Watch, so there is one place to review what you recorded.

# Edit an existing entry

Open a history item when you need to correct its details. Save the update after checking the time, duration, and selected side.

If an entry was created accidentally or is no longer useful, delete it from history rather than leaving a duplicate.

# Export the corrected record

Make corrections before creating a PDF so the exported document reflects the history currently shown in the app. A later edit does not change a PDF that has already been saved or shared; create a new export if you need an updated copy.

# Keep corrections simple

The purpose of editing is to make your own record more useful, not to create a medically complete account of every feed. The app does not validate whether a time or duration is appropriate and does not provide clinical guidance.
