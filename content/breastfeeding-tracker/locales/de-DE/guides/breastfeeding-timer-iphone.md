# Schnell starten

Wählen Sie links oder rechts und starten Sie den Timer. Der Verlauf hält fest, was Sie eingegeben haben, damit Sie später nicht alles im Kopf behalten müssen.

# Wenn der Timer zu spät startet

Sie können eine Startzeit anpassen oder eine bereits beendete Mahlzeit nachtragen. Das macht die Aufzeichnung praktischer, ersetzt aber keine Beratung zu Stillen oder Ernährung.
