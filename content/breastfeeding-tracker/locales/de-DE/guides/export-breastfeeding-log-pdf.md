# Eigene Einträge exportieren

Wählen Sie die Einträge aus, die in eine PDF-Datei aufgenommen werden sollen, und entscheiden Sie dann selbst, wo Sie sie speichern oder weitergeben. Der Export gibt nur wieder, was Sie dokumentiert haben.

# Keine klinische Auswertung

Eine PDF aus der App ist kein medizinischer Bericht. Sie kann ein Gespräch unterstützen, ersetzt aber keine Untersuchung oder individuelle Beratung.
