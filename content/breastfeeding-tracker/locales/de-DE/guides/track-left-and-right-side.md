# Die zuletzt verwendete Seite sehen

Beim Start einer Stillmahlzeit können Sie links oder rechts festhalten. Der Verlauf hilft Ihnen, die letzte eingetragene Seite wiederzufinden, ohne dass Sie sie sich merken müssen.

# Eine praktische Notiz

Die Seitenerfassung ist eine Erinnerungshilfe. Sie sagt nichts über Milchmenge, Wirksamkeit einer Mahlzeit oder die Gesundheit Ihres Babys aus.
