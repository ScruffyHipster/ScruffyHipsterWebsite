# Démarrer au poignet

L’application compagnon pour Apple Watch permet de démarrer ou d’arrêter un repas au poignet. C’est utile lorsque le téléphone n’est pas à portée de main.

# Synchroniser ensuite

Les données terminées se synchronisent lorsque les appareils sont de nouveau connectés. Vérifiez les entrées importantes dans l’historique ; un relevé technique ne remplace pas une appréciation médicale.
