# Exporter vos propres entrées

Sélectionnez les éléments à inclure dans le PDF, puis décidez vous-même où le conserver ou avec qui le partager. L’export ne fait que reprendre ce que vous avez enregistré.

# Pas une évaluation clinique

Un PDF créé dans l’application n’est pas un compte rendu médical. Il peut faciliter une conversation, mais ne remplace ni examen ni conseil individualisé.
